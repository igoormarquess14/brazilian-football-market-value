# legacy/

Everything in this folder is real exploratory work, done during the
research, that **is not part of the published result** in the thesis.
Nothing was deleted — it was only isolated from the reproducible pipeline
in `codes/pipeline/`, to make clear what is the official result and what
was a path tried and not followed.

## `dedup_attempts/`

Player-name deduplication and matching attempts across bases, superseded by
later versions or ending in a file with no downstream use in the real
pipeline (confirmed by tracing each script's input/output paths, not by
assumption — see `docs/pipeline.md`).

## `clustering/`

Hierarchical clustering pipeline for the players (k-means/hierarchical,
dendrograms, silhouette). Not mentioned in the thesis — the published model
is a simple OLS regression on the midfielder subset, with no clustering
step.

## `modelagem_exploratoria/`

Additional regression models estimated during the research but not
published: per-position models (ATA/DEF/GK, with club-clustered robust
standard errors), per-cluster models, and a merge with the RNC club ranking
as an extra explanatory variable. The official model
(`codes/pipeline/13_estimate_mc_baseline_model.py`) uses only 4 variables
and none of these extensions.

## `artifacts/`

Outputs (charts, tables, reports) generated by the scripts above.

## About the absolute paths in these scripts

The scripts in `dedup_attempts/`, `clustering/`, and `modelagem_exploratoria/`
keep the original absolute paths (`C:\Users\IGOR\Desktop\UFSC\TCC\...`) from
the computer where they were written — unlike `codes/pipeline/`, where every
path was rewritten with `PROJECT_ROOT`/`pathlib` and verified by re-running
it. This is intentional: nothing here was re-run or fixed during this
reorganization, by explicit decision — the value of this directory is to
document the research process as it actually happened, not to present it as
ready-to-run code.

# legacy/

Exploratory work from the research that is not part of the published result.
Kept as a record of what was tried; nothing here is needed to reproduce the
thesis model, and none of it was re-run.

| Folder | Contents |
|---|---|
| `modelagem_exploratoria/` | Unpublished regressions: per-position models (ATA/DEF/GK) with club-clustered standard errors, per-cluster models, models with the RNC club ranking |
| `clustering/` | Hierarchical and k-means clustering of players, with its outputs |
| `dedup_attempts/` | Earlier player matching and deduplication attempts between Transfermarkt and FBref, superseded by the pipeline at tag `thesis-archive` |
| `artifacts/` | Charts, tables and reports produced by the scripts above, one folder per run |

The scripts are frozen as written: comments are in Portuguese and file paths
point to the author's machine at the time (`C:\Users\IGOR\...`), so they will
not run without editing.
